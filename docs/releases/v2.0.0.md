# Flowball 2.0.0

Released 2026-09-30. Godot 4.7.2, landscape mobile design; playable desktop sandbox.

## Included

- TV Arcade HUD with the multicolor FLOWBALL wordmark, percentage and goal/attempt score, three miss indicators, and separate timed-phase clock.
- Persistent four-card shot feedback, explicit retry/Restart/next actions, unlocked-shot selection and local progression saves.
- In-engine preparation screen with textured cel-shaded art, simplified crowd, editable Blender sources, GLB exports and texture prompts.
- Stadium clearance correction, visible live run-up angle/distance, and clean transparent boot art with corrected orientation for both feet.
- Regression tests, capture harnesses and actual engine screenshots. Shot formulas and collision dimensions remain unchanged.

## Verification and limitations

Progression, result flow, preparation regression, UI statistics/scaling, support gestures and flight simulator smoke tests passed during this delivery. Five gameplay views and both feet were inspected in Godot.

The existing ShotCalculatorSmokeTest reports 57 passes and one knuckle drift calibration failure (RMS 0.65 m / maximum 2.20 m). Its calculation/physics code and test are unchanged by this release.

The selector contains 60 procedural sandbox scenarios. The authored 10-shot tutorial and 110 historical challenges are future content. Sustained 60 FPS, real iPhone behavior and iOS export remain unvalidated; this tag identifies the source milestone, not an App Store build.

See [implementation and test evidence](../TVArcadeImplementation.md) and [preparation screenshots and reproducible capture commands](../PreparationScreenDelivery.md).
